# Madens klimaaftryk

Slå fødevarers klimaaftryk op og sammenlign dem. Siden er én HTML-fil med alle data indbygget.

**Åbn siden:** https://kaves-engineering.github.io/Mades-Klimaaftryk/

På telefonen kan den lægges på hjemmeskærmen som en app:

- **iPhone:** Safari → Del → Føj til hjemmeskærm
- **Android:** Chrome → ⋮ → Installer app
